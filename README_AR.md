# IPTV Playlist Extractor — Android

تطبيق Android لاستخراج وتحليل قوائم M3U من رابط مصرح لك باستخدامه.

## المزايا
- تحميل قوائم M3U عبر HTTP/HTTPS.
- استخراج أسماء القنوات وروابطها ومجموعاتها وشعاراتها.
- البحث باسم القناة أو المجموعة.
- الضغط على بطاقة القناة لنسخ رابط البث.
- مشاركة القائمة أو حفظها كملف M3U.

## البناء محلياً
افتح المشروع في Android Studio ثم اختر Build > Build APK(s).

## الحصول على APK مجاناً
كل Push إلى فرع main يشغّل GitHub Actions تلقائياً. بعد نجاح التشغيل:
Actions → Build Android APK → Artifacts → IPTV-Extractor-debug-APK.

## تنبيه
المشروع يعرض البيانات الموجودة في قائمة M3U فقط، ولا يفك تشفير البث المحمي أو يتجاوز تسجيل الدخول أو صلاحيات مزود الخدمة.
